Initial release: headless virtualized tree engine with native HTML5 drag-and-drop
(`@treekit/core`) and the Angular `<tk-tree>` adapter (`@treekit/angular`).
Includes tree state with filtering and lazy loading, fixed-height and TanStack
virtualizers behind one interface, pointer DnD with insertion-line feedback and
auto-scroll, and a keyboard-accessible DnD mode with ARIA tree semantics.
